## 打开哪一个文件

| 文件 | 用途 | 说明 |
|---|---|---|
| **`index.html`** | **现场放映（推荐）** | 双击用浏览器打开，按 `F` 全屏。动画、渐显、总览、演讲备注都在这里。设计源文件，改文字就改它。 |
| **`校园作业分析器-路演.pptx`** | **提交 / 备用** | 15 页，标准 16:9。每页都是 3840×2160 的高清成品图，**并带完整演讲备注**（PowerPoint 里按「视图 → 备注页」或演讲者视图可见）。 |
| **`校园作业分析器-路演.pdf`** | **提交 / 打印** | 15 页，每页 20×11.25 英寸（严格 16:9），矢量不变形。 |

> PPTX 用的是「整页高清图 + 原生备注」的做法：保证在任何电脑、任何投影仪上打开都和设计稿一模一样（不会因缺字体而跑版）。**要改文字请改 `index.html`，然后重新生成**（见下）。

## 需要改的地方

**团队名称**默认写的是 **B3组**（取自仓库提交作者）。全文件替换即可：

```powershell
cd 路演PPT
(Get-Content index.html -Raw) -replace 'B3组', '你的团队名' | Set-Content index.html -Encoding utf8
```

其余可替换项：封面上的 `v0.2.0-rc1`、收尾页的仓库地址与二维码。

---

## 改完以后重新生成 PPTX / PDF

```powershell
cd 路演PPT\tools
npm install        # 只需第一次（已预装，可跳过）
node build.mjs     # 渲染 15 张 4K 图 → 重新生成 .pptx 与 .pdf
node build.mjs --png   # 只重新渲染图片
```

需要本机装有 Chrome 或 Edge（脚本会自动寻找）。生成产物会写回 `路演PPT/` 目录，覆盖同名文件。

## 设计说明

版式、字阶、颜色、圆角、动效参数**逐条对照 Apple 线上生产环境的 CSS**（`apple.com/os`、`apple.com/iphone-duo`）实现，不是凭感觉模仿：

- **字阶**：Apple 的 `12/14/17/19/21/24/28/32/40/48/56/64/80`，每个字号严格 `+4px` 行高；为 1920×1080 画布整体上调一档（hero 112px / 标题 64px / 正文 21px）。字重只用 Apple 实际发布的 **400 / 500 / 600**，没有 700，没有斜体。
- **字距**：Apple 对大字号用负字距，但**对中文强制 `letter-spacing: 0`**（Apple 自己写了 34 条 `:lang(zh)` 覆盖）。本 deck 遵循同一规则：中文零字距，英文与数字保留负字距。
- **颜色**：`#000` 深色底 / `rgb(29,29,31)` 正文黑 / `rgb(245,245,247)` 浅灰底 / `#0071e3` 按钮蓝 / `#0066cc` 链接蓝——全部是 Apple 的原始 token，全 deck 只有一个强调色系。
- **卡片**：纯色填充、28px 圆角、**没有描边、没有投影**。Apple 整个 CSS 包里唯一的阴影是 focus ring，所以这里也不用投影。
- **按钮/标签**：`border-radius: 980px` 全胶囊。
- **动效**：复刻 Apple 的 `StaggeredFadeIn`——位移 30px / 0.7s，透明度 0.9s，逐项延迟 0.15s，缓动 `easeInOutQuad`。
- **字体**：内置 **Inter**（拉丁与数字）+ **Noto Sans SC**（中文）共 4.4 MB，全部本地化，**离线也不会跑版**。另外单独声明了一份收窄 `unicode-range` 的 Inter，让中文引号「“”」和省略号由中文字体渲染，避免拉丁标点破坏中文排版节奏。
- 深色页的环境光晕刻意压低到 0.16–0.34 透明度，只做氛围，不抢主体——Apple 的深色区靠产品图而非渐变色块撑场。
