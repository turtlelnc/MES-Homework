feat: 校园作业分析器 v0.2.0-rc1 初始提交

真实 OCR 批改 + 教师复核 + AI 教学分析的全栈实现。

原版能力（v0.1.0-rc5，保持不变）：
- 学校/教师/学生三级账户与数据隔离，CSV/XLSX 批量导入学生
- 作业原件（图片/PDF/DOCX/DOC）解析为可编辑草稿，PDF 服务端转图逐页 OCR
- 逐页识别 + 教师逐题复核后才写入错题本，错题自动生成分步解析与同类练习
- 错题组卷、10 个模型厂商预设、API Key 服务端 AES-256-GCM 加密

本次迭代（v0.2.0-rc1）新增 AI 教学分析：
- 班级学情画像：已复核答卷、得分率、错题数与错因占比、无法辨认题目单独提醒
- 知识点掌握率按题号聚合到校本知识点，从最薄弱开始排序
- 12 类错因体系 + 关键词确定性归类，可按题号调用模型重新归因
- 高频错题讲评单：讲给学生听 / 板书演示 / 讲完立刻检查
- 课堂讲评课方案（时间轴 + 板书设计）、分层辅导、错因干预动作
- 学生跟进名单与个别化诊断，一键把高频错题生成重练作业
- Markdown 讲评单导出与 A4 打印

关键设计：统计全部由已复核数据确定性计算，AI 只负责转写成课堂语言，
模型不可用时核心数字依然可信。

安全与范围修复：
- /api/mistakes 补上 school_id 过滤，避免教师侧跨校读取错题
- users.is_school_admin 纳入初始 schema
- 教学分析的写操作限任课教师本人，学校管理员只读

校验：npm test（24 项）、npm run build、npm run verify:teaching（33 项端到端）
