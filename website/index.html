THE OPERATOR TOOLKIT / 运维命令行

msh
把部署与日常管理，
收进一个命令。

@turtlelnc/msh 是 MES Homework 的便携服务器 CLI。它管理本机运行时、Cloudflare Tunnel、学校开通码、模型凭证、管理员控制台和 MCP 接口。

在 npm 查看软件包 ↗
TERMINAL · MSHv0.2.x
# 安装 CLI（需要 Node.js 24+）
$npm install -g @turtlelnc/msh
# 在本机启动并打开浏览器
$msh --local
# 运行完整环境自检
$msh --check
就绪。你的服务器，你来掌控。
msh --local仅本机启动
msh --all监听所有网卡
msh --cf启动服务与 Cloudflare Tunnel
msh --cfset交互配置隧道和域名
msh --code签发一次性学校开通码
msh --api配置学校模型 API Key
msh --manager打开服务器管理网页
msh --mcp启动 MCP stdio 服务

提示：--all 会监听所有网卡。公开部署前请配置 HTTPS、APP_ORIGIN、防火墙和安全密钥；不要直接把未保护的服务暴露到公网。

01 / GET STARTED

启动你的第一套实例

MES Homework 是需要自托管的全栈应用。准备 Node.js 24 或更新版本，然后在服务器或本机执行：

npm ci
cp .env.example .env
# 编辑 .env：设置 APP_SECRET（至少 32 位）和 DATA_DIR
npm run build
node --env-file=.env server/index.mjs
生产环境必须设置 APP_SECRET。请使用密码管理器生成至少 32 字符的随机值，并妥善备份；现有加密凭证依赖同一密钥解密。

02 / DAILY WORKFLOW

一次作业，如何走完整个闭环

  1. 建立学校与角色管理员使用一次性开通码创建学校，再由学校/教师管理员按权限建立成员、班级与教师关系。
  2. 配置知识库与模型维护校本知识点，在学校设置中选择模型调用模式并配置服务端 API Key。
  3. 创建作业上传原题生成题目草稿，或使用“无需原题 · AI 直接批改”创建答卷级题目快照。
  4. 上传答卷并复核学生上传答卷；教师选择全部复核、仅存疑复核或不复核，并核对异常识别结果。
  5. 分析与巩固教师查看班级教学分析；学生按思考、提示、重做、对照答案、同类练习的顺序订正；家长跟进孩子学情。

03 / CLOUDFLARE WORKER

官网静态托管，API 回到你的源站。

Worker 将 website/ 作为静态官网，/app 跳转到源站应用，并把 /api、/api/*、/uploads 与 /uploads/* 代理到 ORIGIN_URL。SQLite、上传原件和模型调用仍由你自己的 Node 服务负责；不依赖 D1 或 R2。

Browser→Cloudflare Worker→HTTPS OriginStatic assets · API proxy
# 1. 在源站启动 MES Homework（默认 127.0.0.1:8787）
npm run build
npm start

# 2. 用 cloudflared 暴露源站
cloudflared tunnel --url http://127.0.0.1:8787

# 3. 将 HTTPS 地址设置为 wrangler.jsonc 的 ORIGIN_URL 后部署
npx wrangler deploy
不要把临时 Quick Tunnel 当生产入口。生产环境建议使用持久命名隧道和固定 HTTPS 域名；API 服务端的 APP_ORIGIN 必须设置为浏览器访问的精确官网源（含 https://，不带路径或尾部斜杠）。

04 / OPERATIONS & SAFETY

上线前，先把边界讲清楚。

数据与规模

当前使用单机 SQLite 与本地附件目录，适合单机或单写节点。不要把 DATA_DIR 放在网络文件系统，也不要把它当成已验证的多节点集群。

人工复核

AI OCR 与评分可能出错。模型结果和课堂分析不等于准确性保证，学校应由教师复核，并使用授权样本验证识别效果。

密钥与访问

保持 HTTPS、使用有效 APP_SECRET、限制可信模型 API Origin，并按学校/角色控制答卷访问。不要公开 API Key 或管理员令牌。

备份与隐私

定期进行 SQLite 在线备份和隔离恢复演练。备份包含学生相关数据与加密凭证，应限制权限、加密异地保存并按制度清理。

FAQ / 常见问题

部署前，先看这几件事。

它是 SaaS 服务，还是需要自己部署？

这是可自托管的全栈项目。你需要准备 Node.js 24+ 的服务器或本机环境、持久化数据目录、APP_SECRET，以及模型供应商 API Key。Worker 只负责官网静态资源和 API 反向代理。

AI 批改后，结果会自动成为班级统计吗？

不会无条件纳入。班级教学分析只统计教师已复核确认的数据；无法辨认的题目单独显示。直接 AI 批改的答卷级题目快照不进入共享题库的班级讲评统计。

是否包含模型额度或 API Key？

不包含。模型调用使用学校或部署方配置的 API Key，费用与速率限制由对应供应商账户及部署策略决定。

现在能否直接横向扩展到多台服务器？

目前不能把它视为开箱即用的多节点集群。现阶段基于单机 SQLite 与本地文件；多节点部署前需要 PostgreSQL、对象存储、共享队列及迁移/恢复方案。
