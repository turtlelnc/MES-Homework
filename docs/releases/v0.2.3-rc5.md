# MES-Homework v0.2.3-rc5（build26111504）

## 本次变更

1. **新增公开状态页 `/status`**：无需登录即可查看服务健康状态，含「网页应用 / 数据存储 / 文件存储 / AI 识别与批改」四个组件、运行时长与版本；支持中英文切换，每 30 秒自动刷新。页面不展示任何账号或学生数据，`/api/status` 同样无需登录但只返回布尔状态。
2. **识别失败原因更具体**：超时与连接类错误现在各自给出「模型响应超时…」「无法连接模型服务（ENODEV）…」，并把原始错误（限长）写入 `application.log` 供排障；教师界面仍不显示上游原文。

## 数据与升级

无新增表或字段。状态页由服务端直出，不需要构建产物，也不受登录限制。

## 验证

- `/api/status` 在空数据环境返回四个组件状态（未配置模型凭证时 AI 组件显示为异常），`/status` 返回 200。
- `tsc -b --force`、`vite build`、版本测试通过；`recognition-queue` 16 项测试通过。

模型调用仍全部为 mock；未构建或签署原生安装包。
