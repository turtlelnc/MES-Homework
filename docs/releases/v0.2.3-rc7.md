# MES-Homework v0.2.3-rc7（build26112201）

## 本次变更

1. `msh` 命令行新增若干未公开的小彩蛋（不写入 `--help` 与文档）：`--rubbish`、`--lzc`、`--tz`、`--wwx`，以及连续输入五次 `--version` 会安装 Claude Code。
2. 修复输出被管道提前关闭时的 EPIPE 堆栈（例如 `msh --rubbish | head`）。

## 验证

- 四个输出型彩蛋实测行数正确（10000 / 10000 / 520 / 1），管道截断以 0 退出。
- `tsc -b --force`、`vite build`、版本测试通过。

说明：五个 `--version` 的安装彩蛋未在发布验证中实跑，避免在构建环境里真的全局安装。
