# MES-Homework v0.2.2-rc3（build26111403）

## 本次变更

1. **学校注册开通码**：创建学校需要一次性开通码，一码一校、注册时核销。此前任何人打开注册页即可建校并获得该校管理员权限；现在学生拿不到码就无法自行开设“学校”。开通码由 `npm run school:invite -- create|list|revoke` 管理，可设置备注与有效期，列表区分未使用、已使用、已过期与已吊销。无效、已使用、过期统一提示“开通码无效或已使用”，不泄露某个码是否存在。
2. **首次启动引导码**：全新部署既没有学校也没有可用开通码时，服务启动会自动签发一枚引导码，打印在启动日志并写入 `<DATA_DIR>/first-school-invite.txt`；建校成功后该文件在下次启动时清除。原生安装包不含 npm，运维可用捆绑运行时按 `tools/installer/README.md` 的说明签发更多开通码。
3. **批改输出上限提高到 214K**：单次批改的模型输出上限默认由 8192 改为 219136（214×1024），上限由 32768 提高到 1048576。8192 会在长答卷批改完成前触发截断报错；提高后长作业可以一次批改完。该值仍受响应字节上限与供应商支持的 `max_tokens` 约束，供应商拒绝时请按实际支持值下调。
4. **建校事务并发修复**：学校注册原先在事务内等待异步密码哈希，并发请求会互相撞上 SQLite 事务，甚至把同一窗口内其他请求已返回成功的写入一起回滚。现在密码派生在事务外完成，事务内只有同步 SQL，并在事务冲突时返回 503 而不是原始 SQLite 错误。开通码核销与建校仍在同一事务内，注册失败不会消耗开通码。
5. **浏览器回归选择器**：把章节导航的 Playwright 选择器对齐到侧边栏的“工作台章节”，修复此前在 main 上一直失败的 6 个浏览器用例（用户界面早已正确，仅测试选择器过期）。

## 数据与升级

新增 `school_invites` 表，随启动迁移在同一事务内创建并回滚校验；不删除账号、学校、作业或附件。新增环境变量 `SCHOOL_INVITE_REQUIRED`，默认要求开通码，设为 `0` 时恢复开放建校（仅建议本地开发或演示使用）。

**升级前请检查 `.env`**：如果显式写了 `MODEL_MAX_OUTPUT_TOKENS=8192`，升级后仍按 8192 运行，需要手动改为 `219136` 或删除该行使用新默认值。

全新安装或空数据目录启动后，用日志或 `first-school-invite.txt` 里的开通码完成首次建校；建校成功前请勿把该文件或日志片段公开发布。

本次模型调用全部为 mock 或本地 fixture，未使用真实厂商账号完成付费推理验收；未构建或签署 MSI/DEB/RPM/PKG，也未部署到生产环境。
