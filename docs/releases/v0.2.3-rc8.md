# MES-Homework v0.2.3-rc8（build26112202）

## 本次变更

1. `msh --install`：从 npmjs 读取 latest，比本机新时执行 `npm install -g @turtlelnc/msh@latest`；已是最新则只提示。
2. `msh --change`：同样比对版本，但强制重装最新版，用于修复本地安装。
3. 两条命令都先打印当前与最新版本；registry 或 npm 不可达时给出明确错误。

## 验证

- `msh --install` 实测：当前 0.2.3-rc7、registry latest 同为 rc7，输出「已经是最新版本，无需更新」并退出 0。
- `msh --change` 的安装分支未在发布环境实跑（会真的执行全局安装）。
- `tsc -b --force`、`vite build`、版本测试通过。
