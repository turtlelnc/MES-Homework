# MES-Homework v0.2.3-rc1（build26111405）

## 本次变更

1. **命令行便携服务器（npm）**：新增 `cli/` 与两个 npm 包 `@turtlelnc/msh`、`@turtlelnc/mes-homework`（同一份代码，后者依赖前者）。`npm install -g @turtlelnc/msh` 后即可用 `msh` 管理本机实例；数据目录与原生安装一致（Windows `%LOCALAPPDATA%\MESHomework`，macOS `~/Library/Application Support/MESHomework`，Linux `~/.local/share/mes-homework`）。
2. **`msh --local` / `msh --all`**：分别以 127.0.0.1 与 0.0.0.0 启动服务；`--local` 会打开浏览器，加 `--no-browser` 可关闭。启动逻辑复用原生安装的监督器（实例互斥、IPC 正常停机）。
3. **`msh --power [on|off]`**：开关开机自启动，Windows 用 HKCU Run、macOS 用 LaunchAgent、Linux 用 systemd `--user` 单元。
4. **`msh --code`**：交互签发学校开通码（可填备注与有效期）；沿用一次性开通码表，一码一校。
5. **`msh --api`**：列出本机学校、选择学校后为其管理员配置模型 API Key（留空清除），使用与 Web 端相同的 AES-256-GCM 加密与 `provider_settings` 存储。
6. **`msh --list`**：按学校列出本机全部账号。
7. **`msh --check`**：自检 Node 版本、APP_SECRET、配置与数据目录、数据库完整性、`dist/`、端口占用与 cloudflared。
8. **`msh --cfinstall` / `--cfset` / `--cf`**：检测并按平台下载 cloudflared；`--cfset` 会打开浏览器登录 Cloudflare，由用户输入域名后创建隧道、写绑定配置并绑定 DNS；`--cf` 启动服务并同时运行隧道。
9. **`msh --website`**：首次运行设置对外网址/CDN（写入 `APP_ORIGIN`），随后按本地模式启动。
10. **`msh --manger`**：启动服务器管理后台（仅监听 127.0.0.1，令牌校验），可查看概览、改名学校、切换模型模式、重置密码、删除用户、签发/吊销开通码。
11. **`msh --mcp`**：以 stdio 提供 MCP 服务，工具包括 `msh_list_schools`、`msh_list_users`、`msh_issue_invite`、`msh_set_school_api_key`、`msh_server_status`。
12. **`msh --language <zh|en> [--msh]`**：`--msh` 只切换命令行语言，不带则同时写入服务端默认语言；`msh --version`、`msh --github`、`msh --stop`、`msh --status` 一并提供。

## 数据与升级

CLI 与 Web/原生版共用同一配置与数据目录，不会另建数据库。首次运行 `msh --local` 会调用与原生安装相同的 `prepareConfig` 生成 `APP_SECRET`；已有数据库若缺少 `APP_SECRET` 会拒绝启动，请先恢复原密钥。

管理后台的令牌保存在 `<配置目录>/admin-token`（0600），`msh --manger` 每次启动都会打印；不要把它提交或截图外传。

`--manger` 的管理网页目前只覆盖账号/学校/开通码，不含模型凭证编辑（请用 `msh --api`）；`--language` 的服务端语言已写入设置，但界面文案尚未全量翻译。

## 验证

- 在干净的数据目录运行 `msh --check`：全部通过（数据库未创建时按首次启动提示）。
- `msh --local --no-browser`：服务启动，`/api/health` 返回 v0.2.3-rc1，`/api/capabilities` 正确；`msh --stop` 正常停机。
- `msh --code`（管道输入）：签发成功并落库；`msh --list` 正确列出账号；`msh --manger` 页面与 API 需要令牌，未携带令牌返回 401；`msh --mcp` 的 `initialize`、`tools/list` 返回正确。
- `msh --help`、`msh --version` 输出正常，且不会创建配置文件。

模型调用仍全部为 mock；cloudflared 的真实隧道联调需要在用户自己的 Cloudflare 账号下完成，未在自动化测试中执行。
