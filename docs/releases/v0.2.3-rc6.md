# MES-Homework v0.2.3-rc6（build26111505）

## 本次变更

1. **状态页改为事件与历史视图**：参照 status.chatgpt.com 的结构——顶部状态横幅、按分组列出的系统组件（每个组件附带 14 天状态条）、以及「过去的事件」列表；无事件时显示「最近 14 天没有报告事件」。

3. 保留中英文切换与 30 秒自动刷新；`/status` 与 `/api/status` 仍无需登录，只返回状态与布尔值。
