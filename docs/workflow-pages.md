# 同页工作流

按角色整合相关业务，章节控件只滚动定位，不切换子页面或销毁已经打开的表单。

| Before | After | Why |
| --- | --- | --- |
| 教师总览、作业上传、识别复核、教学分析、学生管理、知识库、组卷分散在七页 | 一个“教学工作台”，七个章节同时属于同一文档 | 维护学生/知识点后能直接回到作业草稿，上传/复核/分析连续进行 |
| 学生“我的作业”和“我的错题”分开 | 一个“学习工作台” | 选择中的文件、作答输入不会因章节定位被销毁；错题可在原页刷新 |
| 学校仪表盘/教师管理与学生管理分开 | 一个“学校管理”页面 | 注册教师、查看学校状态、注册/导入学生可在同页处理 |
| 学校模型调用模式/班主任配置与 API Key、OAuth 凭证分开 | 集中在管理员的账户设置页 | 策略切换后立即重新读取凭证权限，保留未提交密钥 |
| 保存账户资料后回到默认业务页 | 保存后留在原设置页 | 不用重新进入设置核对结果 |
| 组卷、讲评或诊断调用浏览器打印整个页面 | 按当前文档范围打印 | 同页的成员名单、其他作业和草稿不会跟着输出 |

家长看板原本已把孩子绑定、作业、错题、学情和报告放在同一页，继续保留孩子选择与权限边界。账户与模型设置仍为独立配置入口；角色业务区不会混合显示。

## 业务衔接

- 教师上传成功：以真实接口返回的答卷 ID 定位到本页复核区，重新读取队列，并打开该答卷；设备端切片和普通上传使用相同交接方式。
- 人工复核或自动复核完成：更新总览与分析数据。题库作业把对应作业交给教学分析；原有“无需原题直批不参与班级题库分析”的边界保留。
- 教学分析重新布置错题：以真实新作业 ID 定位到本页作业区，选择新作业用于提交。选择/请求票据继续防止迟到结果覆盖其他作业。
- 注册/导入学生、新增知识点后，已挂载的关联列表重新读取；不重建正在填写的作业表单。列表读取用版本号忽略旧响应。
- 各区块保留独立的记录选择与草稿，防止查看另一份教学分析时静默改掉当前答卷上传目标；显式完成操作才交接对应记录。

## 加载与状态

`src/WorkflowPage.tsx` 使用章节定位和首次访问挂载。首次看到/点击某个章节才挂载其组件、读取数据；访问后一直保留在当前工作台中，滚动定位不会卸载。未访问的复核、分析、学生、知识库、组卷不会为了整页合并而同时预取。无 IntersectionObserver 的浏览器保留完整功能，降级挂载所有章节。

工作台没有自动调用模型、创建作业或开始识别。模型调用、费用预留、队列与并发限制继续由原接口执行。手机章节条可横向滚动并保持定位入口；键盘定位会把焦点移到对应章节。

学校模式或班主任设置保存后，凭证区重新读取 `/model/access` 与 `/oauth/providers`；保留本地未提交的密钥/模型输入，不通过 React key 重挂载来刷新权限。

## 打印

`src/print-region.ts` 给当前目标及祖先临时增加打印标记，通过 print media 隐藏其他内容；`afterprint` 清理标记。试卷只打印预览，讲评单只打印教学分析区，诊断单只打印所选学生的诊断面板。不将学生 HTML 复制到新窗口，不改变服务器数据，也不卸载页面草稿。

## 验证

浏览器回归覆盖：已有上传/复核/生成/导出流程与迟到响应隔离；七章节间的作业/组卷草稿保留；新增知识点出现在原作业表单；上传后不手工切页即可读取真实答卷；管理员成员页整合；学生文件选择保留；手机章节定位；账户保存留在原页；模型策略修改保留密钥输入；打印只包含所选试卷且正常恢复页面。
